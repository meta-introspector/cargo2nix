# n00b Guide for Batman

## Quick Start

```bash
# Enter development environment
nix develop

# Build LLVM-dependent projects (like kowalski)
cd /path/to/kowalski
cargo build
```

## Available Development Shells

- `nix develop` - Default shell with LLVM, GCC, and Rust toolchain
- `nix develop .#llvm` - LLVM-focused development shell  
- `nix develop .#gcc` - GCC-focused development shell

## Environment Variables Set

- `LIBCLANG_PATH` - Path to libclang for bindgen
- `LD_LIBRARY_PATH` - LLVM and libclang library paths
- `LLVM_SYS_180_PREFIX` - LLVM system prefix for Rust crates
- `CC`/`CXX` - GCC compiler paths

## What's Included

- Rust nightly toolchain (2025-09-16)
- LLVM 18 with libclang
- GCC with GDB
- OpenSSL and zlib development libraries
- sccache for faster builds

## Troubleshooting

If you get libclang errors, the environment should now handle them automatically with the proper LLVM configuration.
