# Tool: simple_monster_traits.rs

## Description
This tool implements a "Simplified Monster Signature Trait System," providing a more straightforward approach to decoupling AST components with Monster Group factor constraints. It uses enums instead of dynamic traits for simplicity, defining a `MonsterSignature` struct that captures prime and exponent for Monster Group classification.
